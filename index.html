Tentang Saya

Latar Belakang & Pendekatan Teknis

Saya adalah lulusan S1 Teknik Informatika dengan fokus utama pada Backend Development dan Software Engineering. Saya memiliki ketertarikan kuat dalam merancang logika sisi server, menyusun alur bisnis aplikasi, dan memastikan integritas data dalam sistem. Dalam proses pengembangan, saya terbiasa menggunakan PHP dengan framework Laravel serta Python untuk membangun arsitektur aplikasi web dan layanan API.

Saya senang memecahkan masalah seputar pengelolaan alur data, mutasi stok atau transaksi, serta integrasi antar-layanan melalui REST API. Untuk mendukung keandalan sistem, saya mengelola database relasional menggunakan MySQL dan PostgreSQL, memanfaatkan Git untuk version control, serta menggunakan Docker untuk menjaga konsistensi lingkungan pengembangan.
